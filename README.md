# 材料配合管理システム

配合レシピの管理と計量ログの記録・分析を行うWebアプリケーションです。

## 📋 概要

このシステムは以下を実現します：

- **材料管理** - 材料マスターの作成・編集・削除
- **レシピ管理** - 配合レシピの登録と材料の関連付け
- **計量ログ** - 実際の配合時の計量データを記録
- **データ分析** - ログの検索・フィルタリング、Excel エクスポート
- **ユーザー管理** - 管理者とワーカーの権限分離

## 📦 セットアップ

### 前提条件

- Docker & Docker Compose
- Git

### インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd material_mixing

# Docker環境を構築・起動
docker-compose up -d --build

# Laravelをセットアップ
docker-compose exec php composer install
docker-compose exec php cp .env.example .env
docker-compose exec php php artisan key:generate

# データベースをマイグレート
docker-compose exec php php artisan migrate

# (オプション) シーダーでサンプルデータを登録
docker-compose exec php php artisan db:seed
```

### アクセス

- **アプリケーション**: http://localhost:8000
- **PhpMyAdmin**: http://localhost:8080

## 🔐 ユーザー管理

### 権限区分

| 権限     | レシピ管理 | 材料管理 | ユーザー管理 | 計量ログ入力 | ログ検索 | Excel出力 |
| -------- | ---------- | -------- | ------------ | ------------ | -------- | --------- |
| 管理者   | ✅         | ✅       | ✅           | ✅           | ✅       | ✅        |
| ワーカー | 閲覧のみ   | 閲覧のみ | ✗            | ✅           | ✅       | ✅        |

### ユーザー作成

1. 管理者でログイン
2. ダッシュボード → 「👥 アカウント管理」
3. 「➕ 新しいユーザーを追加」をクリック
4. 名前、メール、パスワード、権限を入力して作成

## 📖 使い方

### 1️⃣ 材料管理

#### 材料を追加

1. ダッシュボード → 「🏷️ 材料管理」
2. 「➕ 新しい材料を追加」をクリック
3. 材料名（例：塩、砂糖）と単位（例：g, ml）を入力

#### 材料を編集・削除

- 材料一覧から「✏️ 編集」または「🗑️ 削除」

### 2️⃣ レシピ管理

#### レシピを作成

1. ダッシュボード → 「🆕 新規レシピ作成」
2. レシピ名を入力
3. 「既存の材料」から必要な材料にチェック
4. 各材料の数量を入力して作成

#### レシピを編集

1. 「⚙️ レシピ管理」から編集したいレシピを選択
2. 「✏️ 編集」をクリック
3. 材料の追加・変更・削除が可能
   - **既存材料の変更**: チェック状態と数量を変更
   - **新しい材料を追加**: 「新しい材料を追加」セクションに材料名・単位・数量を入力
   - **材料を削除**: チェックを外す

#### レシピを削除

1. 「⚙️ レシピ管理」から対象レシピの「🗑️ 削除」

### 3️⃣ 計量ログ

#### ログを入力

1. ダッシュボード → 「➕ 計量データの入力」
2. レシピを選択
3. 各材料の実際の計量値を入力
4. 計量日時を設定
5. 備考欄に必要な情報を記入して保存

#### ログを検索

1. 「📋 計量ログの確認」をクリック
2. 以下の条件で検索可能：
   - **期間**: 開始日 ～ 終了日
   - **レシピ**: 特定のレシピを選択

#### データをエクスポート

1. ログ一覧ページで検索条件を設定
2. 「📥 Excelダウンロード」をクリック
3. フィルタリング済みのデータがExcelファイルで出力

### 4️⃣ ユーザー管理（管理者のみ）

#### ユーザー一覧

- ダッシュボード → 「👥 アカウント管理」

#### ユーザーを編集

1. 対象ユーザーの「✏️ 編集」をクリック
2. 名前、メール、パスワード、権限を変更
3. パスワード欄を空白にすると変更なし

#### ユーザーを削除

1. 対象ユーザーの「🗑️ 削除」をクリック
2. ※自分自身は削除不可

## 🗄️ データベース構造

### テーブル一覧

- **users** - ユーザー情報
- **materials** - 材料マスター
- **recipes** - レシピ
- **recipe_materials** - レシピと材料の関連付け（数量を保持）
- **production_logs** - 計量ログ
- **production_log_materials** - 計量ログと材料の関連付け（実績値を保持）

## 🔧 トラブルシューティング

### Docker コンテナが起動しない

```bash
# コンテナを再起動
docker-compose restart

# ログを確認
docker-compose logs php
```

### データベース接続エラー

```bash
# マイグレーションを再実行
docker-compose exec php php artisan migrate:fresh
```

### ファイルパーミッションエラー

```bash
# Laravelストレージディレクトリの権限を修正
docker-compose exec php chmod -R 777 storage bootstrap/cache
```

## 📝 主な機能詳細

### 計量ログのフィルタリング

- 複数条件（期間、レシピ）での同時フィルタリングに対応
- フィルタリング結果の集計値（合計）を表示

- フィルタリング条件を適用した状態でエクスポート可能

- 必須項目、一意性、数値形式など多角的にチェック
